Approach

Built with a few principles in mind.

Compatibility Support for the Joomla generations targeted by each extension.
Performance Prefer simple, predictable implementations and avoid unnecessary overhead.
Security Careful input handling, access control and defensive processing where relevant.
Accessibility Usable interfaces and standards-aware behaviour where the extension requires it.
